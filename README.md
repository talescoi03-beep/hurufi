# ✍️ حروفي — تعلّم الكتابة لكبار السن

تطبيق ويب (PWA) يعمل على متصفح الجوال لتعليم كتابة **العربية** و**الكردية البهدينانية** و**القرآن الكريم**،
مصمّم لكبار السن الذين لا يعرفون القراءة: كل تعليمة مسموعة، خط كبير، أزرار كبيرة، وبدون حسابات.

- لا يحتاج خادماً ولا قاعدة بيانات ولا خطوة بناء — HTML وCSS وJavaScript فقط.
- يُحفظ التقدّم في الجوال نفسه (localStorage).
- يعمل بدون إنترنت بعد أول فتح، ويمكن «إضافته إلى الشاشة الرئيسية» ليظهر كتطبيق.

## 🚀 الرفع على GitHub ثم Render (مجاناً)

### أولاً: GitHub
1. أنشئ حساباً على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط **New repository**، سمّه `hurufi`، اختر **Public**، ثم **Create repository**.
3. ارفع الملفات بإحدى طريقتين:
   - **من المتصفح:** في صفحة المستودع اضغط **uploading an existing file**، واسحب **محتويات** مجلد `hurufi` كلها (المجلدات `public` و`tools` والملفات `README.md` و`render.yaml`)، ثم **Commit changes**.
   - **من الطرفية (Terminal):**
     ```bash
     cd hurufi
     git init
     git add .
     git commit -m "first version"
     git branch -M main
     git remote add origin https://github.com/اسمك/hurufi.git
     git push -u origin main
     ```

### ثانياً: Render
1. ادخل [render.com](https://render.com) وسجّل الدخول بحساب GitHub.
2. اضغط **New +** ثم **Static Site**.
3. اختر المستودع `hurufi` (إن لم يظهر: **Configure account** واسمح لـ Render برؤيته).
4. املأ الإعدادات:

   | الحقل | القيمة |
   |---|---|
   | **Name** | `hurufi` (يصبح الرابط `hurufi.onrender.com` إن كان متاحاً) |
   | **Branch** | `main` |
   | **Root Directory** | اتركه فارغاً |
   | **Build Command** | `echo "no build needed"` |
   | **Publish Directory** | `public` |

5. اضغط **Create Static Site** وانتظر دقيقة. سيظهر الرابط أعلى الصفحة.
6. (مستحسن) من **Settings ← Headers** أضف:
   `Path: /sw.js` — `Name: Cache-Control` — `Value: no-cache`
   حتى تصل التحديثات للمستخدمين فوراً.

> **بديل أسرع:** في Render اختر **New + ← Blueprint** واختر المستودع؛ سيقرأ `render.yaml` ويضبط كل شيء تلقائياً.

بعد ذلك، أي تعديل ترفعه إلى GitHub يُنشر تلقائياً خلال دقيقة.

### ثالثاً: على جوال أندرويد
1. افتح الرابط في **Chrome**.
2. من القائمة ⋮ اختر **إضافة إلى الشاشة الرئيسية** (أو **تثبيت التطبيق**).
3. تظهر أيقونة «حروفي» مثل أي تطبيق، وتعمل بدون إنترنت بعد أول فتح.

> **مهم للصوت:** القارئ الآلي العربي يأتي من «محرّك تحويل النص إلى كلام» في أندرويد.
> إن لم يُسمع صوت: **الإعدادات ← إمكانية الوصول ← تحويل النص إلى كلام** واختر محرّك Google وثبّت **العربية**.

## ✏️ إضافة كلمات ودروس ووحدات

كل المحتوى في `public/data/`. بعد أي تعديل ارفع الملف إلى GitHub، ثم **غيّر رقم `VERSION` في `public/sw.js`**
(مثلاً `hurufi-v1` ← `hurufi-v2`) حتى يحصل الجوال على النسخة الجديدة.

### شكل الكلمة الواحدة
```json
{"text": "قط", "emoji": "🐱"}
```
| الحقل | المعنى |
|---|---|
| `text` | الكلمة التي يكتبها المستخدم (إلزامي) |
| `emoji` | الصورة (اختياري — بدونه لا تُستخدم أسئلة الصور) |
| `say` | ما يقرؤه الصوت الآلي إن كان مختلفاً عن الكلمة، مثل `"say": "ألف"` للحرف أ |
| `audio` | ملف صوت مسجّل، مثل `"audio/kurdish/pshik.mp3"` — له الأولوية على الصوت الآلي |
| `accept` | كتابات أخرى مقبولة، مثل `"accept": ["ا"]` |
| `todo` | ملاحظة للمراجعة فقط، لا تظهر للمستخدم |

### إضافة كلمة إلى درس موجود
افتح `arabic.json`، ابحث عن الدرس، وأضف سطراً داخل `"items"` (لا تنسَ الفاصلة بين العناصر):
```json
"items": [
  {"text": "قط", "emoji": "🐱"},
  {"text": "نمر", "emoji": "🐯"},
  {"text": "ذئب", "emoji": "🐺"}
]
```

### إضافة درس جديد
داخل `"lessons"` في أي وحدة:
```json
{
  "id": "l5",
  "title": "ألوان",
  "emoji": "🎨",
  "mode": "loose",
  "types": ["copy", "choose", "complete", "arrange", "see_write"],
  "items": [
    {"text": "أحمر", "emoji": "🟥"},
    {"text": "أخضر", "emoji": "🟩"},
    {"text": "أزرق", "emoji": "🟦"},
    {"text": "أصفر", "emoji": "🟨"}
  ]
}
```
- `id` يجب ألا يتكرر داخل الوحدة نفسها (التقدّم يُحفظ به — لا تغيّره بعد النشر).
- `count` (اختياري): عدد الأسئلة من 8 إلى 12 (الافتراضي 10).
- **ترتيب الدروس في الملف هو ترتيب فتحها**؛ كل درس يُفتح بعد إنهاء الذي قبله.

### أنواع الأسئلة (`types`)
تُوزَّع بالتناوب حسب ترتيبها في القائمة:

| النوع | ماذا يرى المستخدم |
|---|---|
| `letter` / `copy` | الحرف أو الكلمة مكتوبة + صورة + صوت ← يكتبها |
| `see_write` | صورة وصوت فقط ← يكتب الكلمة (يحتاج `emoji`) |
| `listen_write` | صوت فقط ← يكتب ما سمع |
| `complete` | الكلمة ناقصة حرفاً «ن م ؟» ← يكتب الحرف الناقص |
| `choose` | يسمع ← يختار من 4 صور (أو 4 كلمات إن لم توجد صور) |
| `arrange` | يرتّب الحروف (أو الكلمات في الجمل) باللمس |

### أوضاع المقارنة (`mode`)
| الوضع | يستخدم في | ما يُتجاهل |
|---|---|---|
| `loose` | دروس المبتدئين | المسافات، التشكيل، أ/إ/آ/ا، ة/ه، ى/ي |
| `strict` | كلمات وآيات القرآن | المسافات والتشكيل فقط |
| `harakat` | وحدة الحركات | المسافات فقط — الحركة جزء من الإجابة |

وفي كل الأوضاع يُوحَّد الفرق في ترميز الكيبورد (ي/ی، ك/ک) لأنه ليس خطأ كتابة.

### إضافة وحدة جديدة
أضف عنصراً في `"units"`:
```json
{"id": "u5", "title": "الأرقام", "emoji": "🔢", "lessons": [ … ]}
```

### القرآن الكريم
نص القرآن **لا يُكتب يدوياً**. الدروس في `quran.json` تشير إلى الكلمات والآيات بأرقامها:
```json
{"id": "l9", "title": "الفلق ١–٢", "emoji": "٩", "mode": "strict", "ayat": {"surah": 113, "from": 1, "to": 2}}
{"id": "l4", "title": "كلمات", "emoji": "📖", "mode": "strict", "types": ["copy","choose"], "words": ["114:1:1", "114:1:2"]}
```
(`"114:1:2"` = سورة 114، آية 1، الكلمة الثانية)

السور الموجودة حالياً في `quran-text.json`: الفاتحة، العصر، الكوثر، الإخلاص، الفلق، الناس.
لإضافة سور أخرى شغّل (يحتاج Python فقط):
```bash
python3 tools/build_quran.py 1 103 108 112 113 114 110 111
```
ثم أضف اسم السورة في `NAMES` داخل السكربت إن أردت ظهور اسمها.

**طريقة العرض والمقارنة:** تُعرض الآية بالرسم العثماني، ويُقبل من المستخدم الرسم الإملائي (مثل «مالك») أو حروف الرسم العثماني (مثل «ملك»)، لأن رموز الرسم العثماني (ٱ والعلامات الصغيرة) غير موجودة في كيبورد الجوال.

### الكردية — يحتاج مراجعتك ⚠️
- **كل كلمة كردية عليها `"todo"`** — راجع الكتابة البهدينانية لكل كلمة واحذف الحقل بعد المراجعة.
- **التعليمات الكردية** في أعلى `kurdish.json` (`instructions`): `text` يظهر على الشاشة، و`say` يُقرأ بالصوت العربي إلى أن تضيف تسجيلاً في `audio`.
- **الصوت:** لا يوجد قارئ آلي كردي جيد. إلى أن تضيف تسجيلاتك، يقرأ التطبيق الكلمة بالصوت العربي بعد تقريب الحروف (پ←ب، ڤ←ف، گ←ك…) — وهذا **تقريبي وغير دقيق**. التسجيلات هي الحل الحقيقي؛ انظر `public/audio/kurdish/README.txt`.

## 📖 المصادر

- **نص القرآن الكريم:** [Tanzil Project](https://tanzil.net) — الرسم العثماني (`uthmani`) والإملائي (`simple` و`simple-clean`)،
  ترخيص [CC BY 3.0](https://tanzil.net/docs/text_license) (يُسمح بالنسخ الحرفي فقط ويُمنع التعديل).
  النسخ مأخوذة حرفياً من ملفات Tanzil عبر [github.com/risan/quran-json](https://github.com/risan/quran-json)،
  وتجد رابط التنزيل الأصلي وبصمة SHA-256 لكل ملف في `tools/tanzil/SOURCES.json`.
  التعديل الوحيد: فصل البسملة التي تضيفها ملفات Tanzil إلى أول آية في السور (عدا الفاتحة)، لأنها ليست من الآية.
- **تلاوة الآيات:** الشيخ مشاري العفاسي من [everyayah.com](https://everyayah.com) (`Alafasy_64kbps`).
- **صوت الكلمات المفردة:** خادم quran.com (`audio.qurancdn.com/wbw/…`).
  لتغيير القارئ عدّل `ayahAudio` في أعلى `quran.json`.
- **الصور:** إيموجي النظام — لا تحتاج تحميلاً ولا حقوقاً.
- **الخطوط:** Noto Naskh Arabic وAmiri Quran من Google Fonts.

## ❓ ملاحظات

- **بدون إنترنت:** الواجهة والدروس والنصوص تعمل فوراً. التلاوات تُحفظ بعد سماعها مرة، أو اضغط
  «⬇️ حفظ التلاوة» أسفل صفحة القرآن لحفظها كلها مرة واحدة. إن لم تتوفر التلاوة يقرأ الصوت الآلي.
- **الأخطاء:** عند الخطأ يُعرض الجواب ويُقرأ، ثم زر «التالي». في آخر الدرس تُعاد الأسئلة الخاطئة فقط،
  ومن يخطئ مرة أخرى يعود سؤاله لآخر القائمة، ولا ينتهي الدرس حتى تُصحَّح كلها.
- **النجوم:** ٣ بدون أخطاء، ٢ مع خطأ أو خطأين، ١ مع أكثر. لا يوجد أي عقاب.
- **اقتراحات الكيبورد:** الحقل مضبوط على إيقاف التصحيح والإكمال، لكن بعض لوحات المفاتيح (مثل Gboard) قد تُظهر الاقتراحات رغم ذلك. يمكن إيقافها من إعدادات الكيبورد: **تصحيح النص ← إظهار شريط الاقتراحات**.
- **كتابة الحركات (وحدة الحركات):** في Gboard العربي اضغط مطوّلاً على بعض الحروف أو على زر التشكيل لإظهار الفتحة والضمة والكسرة.
- **مسح التقدّم:** من إعدادات Chrome ← إعدادات المواقع ← اختر الموقع ← مسح البيانات.
- **تغيير الاسم:** في `public/manifest.webmanifest` و`<title>` في `index.html` وفي `js/app.js`.
